# NCT-Make-Model-Failures-Prediction-AI-Model
AI Model for predicting NCT make model failures

## Accessing the Jupyter Source in Visual Studio Code

This project is implemented as a Jupyter notebook and can be opened and reviewed directly in Visual Studio Code.

### Requirements
Before opening the notebook, ensure the following are already available on your machine:
- Visual Studio Code
- Python
- The Jupyter extension for VS Code

If these are not already installed, install them before continuing.

### Steps to Open the Project

1. Clone or download this repository to your local machine.
   ```bash
   git clone https://github.com/TomasAuskalnis/NCT-Make-Model-Failures-Prediction-AI-Model.git
   cd NCT-Make-Model-Failures-Prediction-AI-Model
   ```

2. Open the folder in Visual Studio Code.
   - Launch VS Code
   - Click `File` → `Open Folder...`
   - Select the cloned repository folder

3. Open the Jupyter notebook file.
   - In the VS Code Explorer, locate the notebook file with the `.ipynb` extension
   - Click the file to open it
   - VS Code will load it in the notebook editor

4. Run or review the notebook.
   - Use the notebook cells to inspect the model logic, data processing, and predictions
   - Select `Run All` or run individual cells as needed

### Notes
- The notebook can be edited and executed directly in VS Code once the required tools are installed.
- If you encounter a kernel or runtime issue, confirm that Python and the Jupyter extension are installed and available in your environment.

## About This Project
This AI model is designed to predict failures for NCT make and model vehicles by analyzing relevant patterns and data.
